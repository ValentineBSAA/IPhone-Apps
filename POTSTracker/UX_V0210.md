# POTS & Posies v0.2.10 | Medication Library and Cabinet Redesign

**Status: DEVELOPMENT CANDIDATE; physical iPhone acceptance required.** Based on user screenshot and confirmed v0.2.9 testing.

## Scope and source integrity
- **159 offline generic-name entries** with recognizable brand aliases, grouped into 11 *browsing* groups. These are identification/reference shortcuts, NOT personalized medical or treatment suggestions.
- Short educational cautions and links to official NIH NLM MedlinePlus and FDA-submitted labels via DailyMed. Seventeen especially relevant medicine pages have direct MedlinePlus links verified during research. All other entries link to the MedlinePlus drug search landing page. **No claim that 159 individual current labels have been audited.**
- MedlinePlus directory: https://medlineplus.gov/druginformation.html
- Official NLM label database: https://dailymed.nlm.nih.gov/dailymed/
- FDA how to find drug information: https://www.fda.gov/drugs/information-consumers-and-patients-drugs/find-information-about-drug
- POTS medication context: https://www.ncbi.nlm.nih.gov/books/NBK541074/ (no FDA-approved medicines specifically for POTS).
- Examples reviewed: midodrine (supine hypertension), acetaminophen (liver damage and combination products), ibuprofen/naproxen (NSAID bleeding/cardiovascular/kidney), propranolol/metoprolol (abrupt discontinuation), apixaban (bleeding), diphenhydramine (sedation), pseudoephedrine (heart/BP), pyridostigmine (GI symptoms). See direct references in the catalog code.
- This is **not** a clinical interaction checker, prescribing guide, exhaustive safety database, medication dosage reference, pharmacy-verification service, real-time label synchronization or POTS treatment recommendation. Always compare exact label and consult the clinician/pharmacist.

## New interface
- Compact My Medications screen: saved profiles first, **Browse medicine library** and **Add custom medication** in a two-column grid. No duplicated giant introductory card.
- Library: searchable generic/brand aliases, 11 browsing filters, 2-column readable cards, drug detail cards with branded alias label, concise caution and external official link.
- Use-this-name creates a draft with generic name only; **no strength, dose, directions, schedule, refill date or intake status** automatically set.
- Existing manually typed profiles stay intact and receive a caution/detail link only if the name/brand exactly matches a catalog entry. No rename or migration.
- Event logging and opt-in reminders remain separate. No automatic dose-taken entry, no auto supply decrement, no new notification content revealing sensitive medication details.
- Fully free, offline-first, local private storage, iOS 16, original icon art, existing bundle ID, Core Data and backup schema unchanged.
