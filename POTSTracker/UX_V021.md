# POTS & Posies v0.2.1: permission onboarding, Camera Pulse guidance, Journal recovery & polish

## Ground truth and scope
Source: reported physical iPhone v0.2.0 Build 141 testing and approved changes in GitHub Issue #17, plus the two experimental Camera Pulse timeout/stop screenshots. Do **not** treat green compilation as verified physical behavior.

### Preserved
- iOS 16 minimum, exact bundle ID `com.valentinebsaa.potstracker`, and unchanged Core Data model and application support path.
- Twelve approved colorful feature icons and the floral heart Home Screen icon with standard AltStore-readable PNG fallback.
- Strawberry Blossom and soft Midnight Posies modes.
- Journal lock, privacy hiding, direct Face ID access, History filtering and explicit destructive confirmations.
- All manual symptoms, heart rate, BP, journal and feeling logging; app remains free and has no Apple Health or Watch dependence.

## Changes intended for v0.2.1
1. **One-time first-launch review**: before opening the main app, clearly explain local records, no tested backup/export, no cloud account, experimental pulse limitations and optional camera/Face ID access. Acknowledge explicitly to continue. Revisit guidance in More. No OS permission prompts occur at launch because manual logging does not need them. Camera is requested **only after** Start in Camera Pulse; Face ID/passcode is used if Journal Lock is enabled. Users can decline optional permissions and continue logging. This matches Apple's contextual authorization guidance: https://developer.apple.com/design/human-interface-guidelines/privacy and https://developer.apple.com/documentation/avfoundation/requesting-authorization-to-capture-and-save-media
2. **Journal foreground recovery**: no sticky one-shot auth flag, background invalidates stale auth callbacks, foreground starts fresh authentication when locked. Back/cancel leaves safely. A privacy overlay protects switcher snapshots. Repeated Face ID/cancel/retry/background is required physical QA.
3. **Home**: all five feeling buttons stay neutral even if a historically saved feeling matches. Tapping opens an unsaved draft. Remove raw latest private entry titles, saved feeling selection mimicry and explanatory developer copy. Recorded-today dots remain accessible.
4. **Heart Rate**: `Enter manually` and `Camera Pulse · Beta` have equal prominence. Permission is optional.
5. **Camera Pulse**: illustrated fingertip placement, signal status and real optical-waveform visualization; permissive color coverage then conservative periodicity/consistency gate. Stable visual capture around 20 seconds. Explicit reasoned failure/permission/unavailability, strict torch shutdown, 39-second hard cap plus watchdog for stalled frames. A result must never be fabricated or auto-saved. Any estimate must be reviewed in a manual draft. This beta is not a medical device or reliable POTS diagnostic tool.
6. **History**: remove text-heavy explanations while preserving accessible meanings; meaningful empty state with direct Add Entry action, unchanged delete confirmation.
7. **Quality of life**: haptic + VoiceOver announcement only after a successful Core Data save; protect against rapid repeated Save taps; maintain Reduce Motion and larger text.
