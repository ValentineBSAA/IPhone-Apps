# POTS & Posies v0.2.2 — Journal access & Midnight contrast

## Confirmed user feedback
- v0.2.1 Build 158 showed a Journal "Unlocking private Journal" spinner even after Face ID succeeded; user described the Journal locking itself. Issue #21 documents the specific reproduction and privacy considerations.
- User also reported Midnight Posies dark colors were not sufficiently distinguishable/readable and did not fit the visual identity. Light/Strawberry Blossom was already approved and must stay unchanged.

## Scope
1. Separate Journal authentication gate from actual navigation/session lifetime. Only lock on genuine exit from Journal or app background, not when the gate changes from spinner to unlocked content. Ignore transient `.inactive` due to Face ID.
2. Keep recoverable Back/Retry, avoid stale callbacks, preserve private Journal access, and add unit tests for locked/inactive/active/background states.
3. Midnight: higher-contrast charcoal/plum background, visibly lifted cards, warm blush links/icons, cream/pink-white primary text and explicit soft-lilac secondary/tertiary text. Increase card outlines and inactive tab/icon legibility.
4. A deeper raspberry `potsButtonFill` (distinct from pale blush link color) provides readable white text on primary buttons, selected days and active symptom choices.
5. Preserve the entire light palette, existing 13 approved icons, Core Data model, iOS 16 baseline, stable bundle ID, AltStore signing compatibility and optional camera pulse beta.
6. Add `MidnightContrastTests` to validate secondary/tertiary 4.5:1 or higher against all surfaces, accent 4.5:1 on muted cards, white labels 4.5:1 on prominent button fill. These are automated palette tests, not comprehensive on-device accessibility certification.
