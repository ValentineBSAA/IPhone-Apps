# POTS & Posies v0.2.9 | Daily Care Physical QA

This is a **test candidate** derived from v0.2.8, not a stable release. All-free, privacy-first native iPhone, iOS 16+, same com.valentinebsaa.potstracker ID and unchanged Core Data store.

## Implemented in candidate
- Four user-chosen hydration quick amounts (defaults 125/250/350/500 mL), independent four sleep/rest minutes (defaults 15/30/60/90).
- New editor validates four distinct positive whole numbers; Save, Cancel, and Restore original buttons are independent. Tapping selected presets again clears them. No entry is saved by selecting a shortcut.
- Cabinet displays latest explicitly recorded medication event and offers manual logging. Planned is **not** taken. Editor remains visible if profile save fails.
- Observation highlights show separate sleep and rest minutes and medication Taken/Skipped/Planned/Other counts, not adherence scores.
- Historical records, backups, reminders, optional hydration goal, original icons, app theme and Journal Lock retained.
