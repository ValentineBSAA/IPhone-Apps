# POTS & Posies v0.2.4 • Full-feature expansion / physical QA

**Scope:** The next functional milestone after the user confirmed v0.2.3 tab routing, improved Midnight colors, and Journal Face ID. Priorities follow `PREMIUM_FEATURE_ROADMAP.md`. All features stay **free**, private and usable manually on an iPhone without an Apple Watch, accounts, Apple Health, advertising or subscriptions.

## Implemented in source (hardware results are pending)

### Working daily-support trackers
- **Hydration:** Drink type, fluid amount in mL, optional **mg sodium** (explicitly not grams of salt), context and notes, local backdated multiple entries. No treatment targets.
- **Medications:** User-entered medication/supplement name, optional label/dose text, explicit Taken/Skipped/Planned/Other status, time and context, multiple entries. No automatic adherence assumptions or dose recommendations.
- **Sleep & Rest:** Sleep/rest period, duration in minutes, optional perceived quality, fatigue/brain-fog context, notes.
- **Posture:** Optional sitting/lying/standing observation with manually entered bpm and time in position. **No standing prompts, clinical test, diagnostic score or threshold.** Stop if uncomfortable.
- All four persist in the existing local Core Data SQLite model using versioned encoded metadata stored in the pre-existing `source` field. **No schema migration**, no removal of saved entries. New records appear in category History and can be edited/deleted with existing confirmation protections.

### Previously empty More tools
- **Calendar:** Real monthly date grid, twelve-month year gallery, days with entries, selectable day timeline, and entry editor navigation. A blank day means *not recorded*.
- **Reports:** Native iOS Charts based on actual logs, days recorded, manual BPM scatter, symptom-frequency counts, and a table alternative. Free 7/30/90/365-day and lifetime views; no fabricated zeros, causal conclusions or medical scoring.
- **Reminders:** User-created local daily/weekday schedules, medication/hydration/check-in/rest/personal categories, edit, enable/disable, quiet hours and private/neutral notification text. Permission requested only on opting into reminders. Up to 8 scheduled rules to stay within iOS pending notification limits. Reminder notifications never silently record medication as taken.

### Data ownership tools
- **CSV** with real timestamps, stable identifiers, explicit values/units and spreadsheet formula escaping.
- **Multi-page PDF** personal summary with selected entries and optional notes.
- **JSON** full local backup with version, stable IDs, original timestamps, units and notes. Generated only on user action and shared via native Share Sheet.
- **Preview+restore:** strict format/schema validation, duplicate-ID checking, imported-item preview, existing-entry skip/no overwrite and one-shot Core Data commit/rollback. Journal-containing restores require unlocked private access.
- No automatic upload; files shared at the user's discretion. **Backup files are not separately passphrase-encrypted.** Use secure storage and test recovery with synthetic data.

### Existing functionality deliberately preserved
- Approved Home Screen blossom ECG icon and **all 12 original full-color feature artworks**.
- Strawberry Blossom light and high-contrast Midnight Posies, System appearance, four-tab root navigation and persistent Home customization.
- Journal privacy with Face ID/passcode, background relock, corrected navigation and protected deletion, Camera Pulse beta (nonclinical and only on request).
- Offline use, iOS 16 minimum, bundle identifier `com.valentinebsaa.potstracker`, existing SQLite/entries, original Category/Check-in manual logs.

## Deferred to avoid an unsafe all-at-once scope
- Passphrase-encrypted backup; automatic background backups and sync.
- Clinical-dose guidance, sodium targets, diagnostic standing tests or emergency detection (not planned).
- Arbitrary custom tracker schema, body-map interface, and Home widgets; advanced observational factor comparisons require sufficient real data and thorough testing.
- Background notification snooze action categories, appointments and clinician-specific templates; simple Journal notes can hold questions in this build.
- Localization and third-party app integrations.

**Medical and release limitation:** This is a personal log, not a medical device. A compiled and simulator-tested IPA is not a physically validated health app. No personal records or backup files belong in the public GitHub repository.
