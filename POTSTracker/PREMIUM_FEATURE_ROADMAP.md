# Premium-quality Features, Free Forever: POTS Tracker Research & Roadmap
**Research snapshot:** November 19, 2026 | **Status:** original specification; see v0.2.4 implementation update below.
**Audience:** an iPhone user tracking POTS symptoms with manual entries; **no Apple Watch** or required peripherals.
**Product goal:** the useful capabilities other apps sometimes sell as Premium/Pro, without subscriptions, advertising, tracking accounts or any paid tier.

## Priorities, flows and acceptance criteria

### P0 | Build 1 | Trusted foundation
- [ ] Native iOS 16+ SwiftUI Home: 12 feature icons, concise text labels, large tap targets and separate main app icon, using exact approved assets
- [ ] Real on-device persistent store (Core Data/SQLite); schema migrations and no login/cloud required; settings for data retention and deletion
- [ ] 1-tap "How am I?" daily check-in: Better / Usual / Worse / Much worse / Not sure, or Skip. No mandatory forms or streaks.
- [ ] Fast symptom episodes: predefined POTS symptom set + custom names, severity 0–10, optional onset/duration, position, possible trigger, notes and functional impact; multiple per day
- [ ] Manual heart-rate (bpm) and blood-pressure (systolic/diastolic mmHg) log, with positioning (lying/sitting/standing), provenance/device note and time since position change
- [ ] Real seven-day overview of entries and optional symptom severity; edit/backfill/delete; blank days = **not recorded**, not score 0
- [ ] Daily journal, search/filter by date and simple event timeline
- [ ] Clear offline and empty states; test/demo data visibly labeled and segregated from actual private data
- [ ] Fatigue-friendly quick log: one-screen, save in minimal taps; adjustable text and contrast

**Acceptance:** data survives force quit, reboot, app update and airplane mode; repeated events never collapse into one; restoring/backdating updates the correct date. No fake recorded readings. No actual vitals are generated by the iPhone.

### P1 | Build 2 | Comprehensive tracking
- [ ] Fluids in mL/oz with entry time and type; sodium **mg / g sodium** distinct from **g of salt**; conversion labels correct, no default medical target
- [ ] Optional user-entered clinician-specified targets (water/sodium), with no auto-prescription and easy disable
- [ ] Medications and supplements: user's prescribed item, schedule, recorded taken/skipped time, dose edits, start/stop dates, side-effect notes; do not suggest doses
- [ ] Optional logs: fatigue, brain fog, sleep duration/quality, rest, meals, activity, heat exposure, temperature, caffeine, compression use, menstrual context and customizable events. All optional/hidden by default.
- [ ] Posture observation session: timestamped readings grouped by lying/sitting/standing, timer **only for recording**, optional symptoms, stop/cancel; no diagnosis, unsafe standing prompts or threshold-based health labels
- [ ] Local scheduled notifications with quiet hours, privacy-preserving lock-screen text and full functionality when denied
- [ ] Simple appointments/clinician notes and questions list, optional
- [ ] Flexible customizable quick-entry presets without requiring users to configure everything before day one

**Acceptance:** unit conversions covered by automated tests; medication reminder never implies a dose was taken unless explicitly recorded; unfinished posture sessions are saved as incomplete, not interpreted.

### P1 | Build 3 | The usually-paywalled reporting suite
- [ ] Free date selections: 7 days / 30 days / 90 days / 365 or 366 days / custom / lifetime, with no expiration
- [ ] Day, month and year calendar heatmap *plus* accessible list/table alternative; missingness clearly shown
- [ ] Filtered symptom frequency and severity trends; heart rate and BP series with units, posture and timestamps
- [ ] Weekly and monthly comparisons with counts of days logged, not fabricated daily averages for missing days
- [ ] Unlimited doctor-ready PDF: brief one-page summary plus optional details, entries, medications/changes, charts and notes; no diagnosis or health score
- [ ] Unlimited CSV export in structured, machine-readable format (one file per data type or clearly typed rows) plus readable JSON backup
- [ ] Preview and choose which categories / personal fields to include before exporting; share deliberately via iOS Share Sheet
- [ ] Local manual backup and restore with integrity check, previews, duplicated-ID policy, and documented encryption/passphrase option; no automatic public upload
- [ ] Privacy settings: export warning, delete-all confirmation, neutral notifications, local lock when feasible

**Acceptance:** PDFs and CSVs match database for sample and 365/366-day synthetic datasets; backup round-trip retains original timestamps/units; report generation works offline.

### P2 | Build 4 | High-value advanced extras (after stability)
- [ ] Observational insight comparisons: "On days with [factor] vs without [factor], symptom reports were [x/y]"; show sample sizes, denominators, missing days and uncertainty; **never causal claims**
- [ ] Time-of-day pattern view and optional delayed-factor comparisons, only if sufficient data; avoid arbitrary statistical confidence
- [ ] Custom symptom/measurement trackers, units and display labels with schema-safe versioning
- [ ] Optional simple pain-body map (native vector, without requiring more generated app icons); severity and location history
- [ ] Custom reminder schedules, check-in presets and iPhone home-screen widgets **with neutral private defaults**
- [ ] Optional personal care-plan notes and tap-to-call contact shortcut, no automatic emergency detection or messaging
- [ ] In-app tutorial explaining how to log, read charts, export, and what results do **not** mean
- [ ] Optional localization later, based on user requests

**Acceptance:** insights do not display false associations with too little data; custom tracker data survives upgrades; widgets don't expose health details on lock screen without explicit selection.

## Guardrails
- POTS diagnosis requires a clinician and more than heart-rate values. This is a journal, not a diagnostic, medical-decision or automatic emergency device.
- Do not instruct a person feeling faint to continue or repeatedly perform standing tests.
- Fluids/sodium/supplements/medications are clinician-directed; do not generate universal treatment goals.
- Do not issue high/low reading diagnoses or automated medication recommendations.
- If severe chest pain, breathing trouble, unresponsiveness, major fainting injury or other emergency occurs, user should seek urgent medical care. App is no emergency monitoring substitute.
- No automatic GPS collection, health-record scraping, wearables, AI chatbot, background recording, contact uploads, ads or analytics in first releases.
- No sending personal health logs or production backups to GitHub. Repo remains publicly readable.
- iOS file protection, user-controlled export and deletion, and accurate privacy policy are mandatory before sharing with anyone.
- FTC Health Breach Notification Rule may apply to some US consumer health apps even when HIPAA does not; review scope before public distribution. Do not make unsupported "HIPAA compliant" claims.

## Build strategy
**No gold-plating before trustworthy storage and the first successful physical-device logging test.** All capabilities remain free when shipped; it is not necessary to have every advanced feature functional in Build 1.

Expected delivery order: **B1 functional manual logging -> B2 full condition tracking -> B3 free premium reporting / backup -> B4 advanced observational insights / polish**. Each build needs regression checks and an honest test matrix.

The family member's health specifics are not necessary to start development; keep later preference requests optional and private.


## Implementation update • v0.2.4 (2026-11-20)

**Implemented and tested in development branch** (GitHub Actions [run 44717465530](https://github.com/ValentineBSAA/IPhone-Apps/actions/runs/44717465530)): the original 12 custom-artwork feature destinations, local Core Data entries, editable History, Journal Lock, optional Camera Pulse beta, hydration, medication, sleep/rest and posture observation trackers, month/year calendar, 7/30/90/365-day and lifetime reports, local reminder schedules with quiet hours, optional iOS notifications, and user-triggered PDF/CSV/JSON export with validated duplicate-safe JSON import. All preserve iOS 16 and remain free, offline-first, with no Watch or Apple Health.

**Physical iPhone acceptance remains outstanding** for all new features, including backup file creation, preview, restore round-trip, real notification delivery, accessibility and long-range reports. Review [UX_V024.md](UX_V024.md) before declaring the update production-ready.

**Deferred and not secretly simulated:** encrypted/passphrase backups; custom tracker schema; body-map, widgets, arbitrary event categories; clinician appointment templates; full unit-selector/salt conversions beyond correctly labeled mL/mg inputs; notification snooze; factor correlations; medication dosing targets or automatic adherence; emergency detection or clinical recommendations.

Original P0/P1/P2 checkboxes are the full specification, not an assertion that every advanced acceptance criterion has passed.
