# POTS & Posies v0.2.0 — Gentle Midnight, Premium History, Direct Journal

## Ground truth: physical iPhone v0.1.9 Build 127 screenshots
- **Light mode:** user likes the current rose/ivory presentation; preserve it.
- **Midnight mode:** user finds absolute OLED black overly dark and harsh for this app. Use softer plum-charcoal canvas, plum cards and rose accents.
- **History:** functional but the plain Week/Month/Year/All segmented tabs and date/category rows need a completely more polished, convenient visual presentation.
- **Journal:** when lock is on, tapping Journal must invoke iPhone Face ID/passcode immediately and open records on success, not stop at a second unlock page; with lock off it must open directly.
- **Apple Health:** user explicitly requested full removal rather than additional AltStore/HealthKit troubleshooting.
- **Icon:** user wants AltStore to show the current POTS & Posies icon, not a cached older image. Icon preview cannot be forced on the AltStore side, but we can improve the archive.
- **Preserve:** working save/edit/delete, private Journal access, empty-day semantics, four tabs, custom artwork, optional camera pulse beta, data compatibility and accessibility.

## Implementation shipped in source for v0.2.0
1. Remove Apple Health from the More review grid, feature registry, navigation destinations, data-access code, entitlement file, privacy guidance and iOS Info.plist; keep camera pulse separate and optional.
2. Midnight Posies backgrounds use soft plum-charcoal rather than #000, with legible warm text, raised berry/plum cards and blush highlights. **Strawberry Blossom light theme preserved**. Appearance preference still supports System / Blossom / Midnight.
3. JournalProtected now invokes the system authentication prompt on opening when locked. Nothing private is rendered before success; cancellation returns to the previous screen. Existing configuration and scene-background relock remain. Without lock, Journal opens directly.
4. History uses a private-data-safe welcome card, accessible 2×2 period cards instead of system segmented tabs, a tappable 7-day browsing strip, improved month/year views, and richer dated record/category cards. Missing entries are never mistaken for symptom-free days.
5. Existing swipe actions (full swipe to edit/confirmation), atomic day/category deletes, typed DELETE for all-history clearing and Journal unlocking for private-history deletion stay intact.
6. GitHub's iOS app icon remains the full-quality floral artwork. The packager rewrites **uncompressed/standard PNG icon previews** at `AppIcon60x60@2x.png` (and iPad fallback) from the approved source *after Xcode's optimized PNG generation*, to make previews easier for sideload tools to decode. **AltStore may still cache its own old preview**, which the app cannot guarantee to refresh.
7. Preserve `com.valentinebsaa.potstracker`, iOS 16.0+, Core Data model, local data location and user-controlled camera pulse beta; no Apple Watch, accounts or subscriptions.

## Safety and release limits
- A signed install and physical tests are mandatory even if GitHub CI passes.
- HealthKit removal is intentional; there is no Apple Health integration to test.
- Experimental camera pulse is **not validated for POTS or clinical decisions**. Do not rely on it over an independent monitor.
- There is **still no completed and verified backup/export/restore**. Do not use irreplaceable health records or delete the existing installed app as a shortcut to fix icon caches.
