# POTS Tracker v0.1.6: Reliable swipe and bulk History deletion

## Real iPhone 16e feedback, November 19, 2026
- User verified v0.1.5's custom titled check-in is saved, the Feeling status dot fills correctly, and History's day→category→record grouping looks much cleaner.
- After all records were deleted, the Feeling dot cleared. This is **correct**: a filled dot means 'logged today', not a wellness rating.
- User reports record swipe left/right is finicky, can require starting at particular locations, and looks like a long-hold-swipe. The revealed buttons sometimes overlap the record content.
- User wants to clear a whole History group by swiping, and clear the entire saved history.
- Save check-in requiring selection of a feeling is intended and should **not** be changed.

## Changes in v0.1.6
- Replace the old record-only offset/long-press menu with a single full-width reusable HistorySwipeSurface for date, category and entry cards.
- A quick horizontal flick from anywhere on each card works; short swipe reveals a labeled action rail, decisive swipe invokes the action immediately. A destructive action **never deletes immediately**, but opens confirmation.
- Right swipe: Edit for entry, Open/Close for date and category. Left swipe: Delete entry, Delete group or Delete whole day.
- Keep vertical scrolling usable, accessible actions and the approved native card design. Remove the competing long-press context menu from these swipe surfaces.
- Screens own confirmations and resolve immutable Core Data record IDs, preserving the v0.1.4 final-record crash fix.
- Group and day deletions are one atomic Core Data save operation, with rollback on error. No partial delete on failed save.
- History All tab contains a dedicated 'Clear all saved history' swipe row. It requires typing DELETE and confirming. Warn that local export and restore are not yet implemented.
- Dots update based on remaining entries, so removing the last check-in clears the Feeling dot; no false medical-status conclusions.
- No changes to check-in Save validation, icons, bundle ID, storage schema, iOS 16 support, Home customization or offline-only policy.
