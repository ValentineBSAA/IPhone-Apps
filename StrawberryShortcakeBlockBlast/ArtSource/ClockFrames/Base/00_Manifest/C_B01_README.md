# Berry Berry Blast · Base Day / Night digital clock frame · Batch C-B01

Two approved source illustrations, **regular Day** and **regular Night**.
These are **horizontal UI frames**, NOT analog clocks and NOT image-rendered time.
SwiftUI overlays real, localized h:mm a live text in the empty center.

## Reviewed/accepted
- Day: pink gingham bow, strawberry blossom side trim and scalloped heart lace.
- Night: purple gingham bow, moon/stars, purple glass face and lace.
- Each original PNG is 1774 × 887 and has native transparency (RGBA).
- RGBA_Candidates contain exact byte-identical copies of those originals;
  no background removal is needed or performed.
- Includes checkerboard/cream/dark proof sheet.
- Visual acceptance is NOT physical device approval, screenshot QA or shipping.

## Batch boundaries
These TWO are the regular non-holiday baseline. **They are not**
the Thanksgiving, Halloween, Christmas or Birthday frames.
Keep them separate from all existing and future Night Garden source assets.
Before Xcode import, verify live text contrast, clock height and device safe area.
No committed game code or IPA in this package.

## Clock design rule for future work
One new asset generated per response (not eight automatically).
Name clear Day/Night and event; show it to owner before marking approved.
Place real dynamic 12-hour time (h:mm a) in SwiftUI only.
No clock hands, tick marks, static digits, analog shapes or fictional time.
