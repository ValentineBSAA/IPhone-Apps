# Berry Berry Blast · H1-B04 More Adventures seasonal tiles

Four holidays x Day/Night = 8 source PNG originals, all owner visually approved.
Semantic use: Home More Adventures tile, which opens Berry Blitz / Cozy Cottage /
Strawberry Nightmare. Three pictogram-only signposts are intentionally preserved.

All 8 source PNGs are byte-identical to original generated files and have SHA-256 checksums.
MA-01 and MA-03 already contain native RGBA; alpha candidate is an identical byte copy.
MA-02, MA-04, MA-05, MA-06, MA-07, MA-08 are RGB with apparent checkerboard
background. Their RGBA candidate versions were created non-destructively by foreground
segmentation; review foliage tips, white flowers, sky, signs, candle light, edges
and transparency holes before treating any candidate as final.

MA-04 uses the SECOND/latest Christmas Night option that owner continued past;
first alternative is not included in approved source eight.

A technical PNG alpha channel does NOT mean the matte is aesthetically accepted.
Use checker/light/dark proof sheets, 64/96/144px proof and physical device QA.

40 approved Night Garden artwork pairs, Berry Story, Daily Harvest, cottage art,
clock frames, player saves, currency, daily status, or gameplay functions.
