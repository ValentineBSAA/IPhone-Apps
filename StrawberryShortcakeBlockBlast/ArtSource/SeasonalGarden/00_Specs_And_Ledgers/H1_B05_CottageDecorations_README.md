# Berry Berry Blast · My Strawberry Cottage H1-B05 source+RGBA QA bundle

The eight visuals (Halloween, Christmas, Thanksgiving, Birthday Day/Night) were
approved individually by the owner. This batch represents the Home tile that opens
the **player-owned decoration editor** (art name CottageDecorations), NOT a
replacement for the eight prior H1-B01 Cottage/Home Classic hero images.

The Original folders contain the **exact untouched PNG bytes** that were
originally generated; no destructive editing has taken place.
CD-03 Christmas Day uses the *second* of two alternatives, the last one shown
before the owner replied "Good continue"; the first candidate is not counted.

CD-01 through CD-07 are original RGB PNGs: six with light/checkerboard-style
background and one (CD-07 Birthday Day) with a black background. Their *separate*
RGBA candidate cutouts use foreground segmentation, matte feathering, and
preserve the original RGB channels. The seven *candidates* have technical alpha
transparency, but edge fringes, thin vines and gaps still REQUIRE OWNER REVIEW.
CD-08 Birthday Night was native RGBA; candidate is a byte-for-byte copy.

Four preview sheets show checkerboard, cream, plum UI background, and actual
64/96/144px icon sizes. Do not treat technical alpha as visually final, or
consider these icons imported into the game. After edge approvals, upload this
ZIP as the exact GitHub Release asset for checksum-pinned importer into isolated
art branch, verify import, then later separately integrate and test on iPhone.

This work does NOT replace approved Night Garden, digital clock, Berry Story,
Daily Harvest, More Adventures, H1-B01 original cottages, or game saves/rewards.
