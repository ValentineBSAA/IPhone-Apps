# Build 26 — LumaOS refinement (1.5.1)
Creator feedback: consolidate fixes, audit before implementation, no story spoilers, use GitHub CI, physical QA on iPhone 16e only after a verified package.
## Findings and shipped scope
- Build 25 forced background and event checkpoints regardless of interval. Separate live world persistence from periodic rollback checkpoints; Off disables scheduled checkpoints entirely. Default five minutes on new settings, preserve existing interval choice. Three existing manual and auto slots retained; global 60-second manual cooldown is a proposed balancing default, persisted across launches; no manual save during the cooldown.
- Successful load must clear navigation, active thread, banners, pending authentication and recent apps, then show the existing fictional userspace restart and return to the lock screen. Failed load retains current game. Pause delivery/ticking during reboot; no real system reboot.
- Distinct Messages and Contacts views, shared contact identity, search, contact action links, compact optional suggested replies, native-style lists. Phone icon launches fictional Favorites/Recents/Contacts and local outgoing call simulation, no real dialing. Call history and favorites persist and roll back with world snapshots. No voiced calls/voicemail or new narrative claimed.
- Settings reorganized into display/connectivity and security, consistent background/icon labels. Preserve all existing controls, approved assets, audio, story fixtures and bundle ID.
- Tests: cooldown across slots and recreated store, periodic interval changes and Off, history/favorites encode/decode, existing regression suite, exact release metadata, assets, native build and IPA gate.
