# Berry Block Blast 0.5.8 artwork intake

Place the file **Berry_Block_Blast_0.5.8_19_ArtCatalogs_CloudReady.zip** in this directory on the
`feature/berry-058-polish` branch. Do not unzip manually. The Codemagic
`berry-block-blast-unsigned` workflow extracts its 16 `.imageset` asset catalogs
into the Xcode project before compiling.

The filename must be exact, including capitalization.

passes, and the game is verified on physical iPhone hardware.
